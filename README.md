Ответы на вопросы:
1. Console.Write() - выводит текст без перехода на новую строку.
Console.WriteLine() - выводит текст и после этого переходит на новую строку.
2. Произойдёт ошибка, потому что 3.14 - дробное число, а int хранит целые числа.
3. Потому что оба числа типа int, поэтому выполняется целочисленное деление. Чтобы получить дробный результат можно использовать double.
4. var позволяет компилятору определить тип переменной  автоматически по значению, которое ей присваивается. в C# тип переменной определяется при компиляции программы и не может быть изменён на другой тип.
5. C# и .NET используются в таких крупных компаниях и проектах как: Microsoft, Unity-игры, Яндекс, Т-банк и во многих других.
